# 카드 디펜스 작업 계획

> 2026-11-05 튜터 초안. **최명준과 합의 전.** 2026-11-05 결정: 마우스 피킹은 이현수(H1), 카메라는 최명준(M15). 영역별 담당은 회의에서 다시 정한다 (`카드디펜스-작업목록.docx`). 제안서(v2)에 맞춰 외곽선·카드팩 개봉 연출·파티클 인스턴싱은 권장으로 내렸다. 하루 = 평일 2시간, 주말 4시간으로 잡았다.
> **2026-11-05 이후**: 엔진 골격과 기술명세를 폐기하고 코딩 시험 복습 코드에서 다시 시작했다. 아래 표의 파일 경로(`Engine/`, `Game/` 등)는 옛 골격 기준이라 지금은 없다. 작업 항목만 참고한다.

**규칙 세 가지**

1. 프로토타입은 버리는 코드가 아니다. 이미 있는 함수에 **가장 단순한 버전**을 채운다. 본 개발은 같은 함수를 두껍게 만든다.
2. 각자 **자기 파일만** 고친다 (아래 '코드 지도'). 겹치는 곳은 `EffectSystem::Spawn` 호출 하나뿐이다.
3. 막히면 하루를 넘기지 않는다. 그날 안에 서로 묻는다.
