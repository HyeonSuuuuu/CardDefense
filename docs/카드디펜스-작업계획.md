# 카드 디펜스 작업 계획

진행 상황(완료 여부)은 GitHub **[마일스톤](https://github.com/HyeonSuuuuu/CardDefense/milestones)** 과 **[이슈](https://github.com/HyeonSuuuuu/CardDefense/issues)** 에서 본다. 이 문서는 전체 흐름과 규칙만 담는다.
날짜를 바꾸면 이 문서와 이슈 제목을 같이 고친다.

## 한눈에

```
11/10 (화)        제안서 면담
11/10 ── 11/16   1주차: 상자로 한 판          ★ 11/16 점검, 권장 항목 범위 결정
11/17 ── 11/23   2주차: 마우스로 한 판        ★ 11/23 점검
11/24 ── 11/30   3주차: 그래픽스 효과         ★ 11/30 기능 동결
12/01 ── 12/06   마무리: 버그, 보고서, 영상   ★ 12/6 (일) 23:59 e-class 각자 제출
12/9 (수)         발표 (1반, 팀별 3~5분 발표 자료와 데모)
```

## 규칙

1. **작업이 끝나면 커밋 메시지에 `fix #번호`** 를 넣는다. push하면 그 이슈가 자동으로 닫힌다.
2. **점검일(월요일)마다 실행 화면을 같이 본다.** 점검 기준에 못 미치면 그 주의 권장 항목을 뺀다.
3. **밀리면 빼는 순서:** 외곽선 → 유물·주문 → 둥근 칸(네모 칸 + 텍스처로 대신) → 파티클 종류 줄이기. 필수 항목은 빼지 않는다.
4. 11/30 이후에는 새 기능을 넣지 않는다.
5. 기능을 끝낼 때마다 AI 사용 일지에 한 줄 쓴다 (물어본 것 / AI 결과 / 직접 검토·수정한 것 / 확인 방법). 최종 보고서에 AI 활용 사례 3~5개와 AI 답변의 한계, 직접 한 작업을 써야 해서 그 근거가 된다 (과제 안내 PDF 8쪽).
