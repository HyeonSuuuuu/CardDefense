# 카드 디펜스 구현 자료

> 2026-10-22 정리. 링크는 검색으로 확인한 것과 이미 알려진 공식 사이트만 넣었다. 라이선스는 받기 전에 각 페이지에서 다시 확인한다.
> 외부 라이브러리를 쓰면 제출물에 포함해야 한다(`2026-2 컴그 최종 프로젝트.pdf` 6쪽 "오픈지엘 외 특별한 라이브러리").

## 1. 기술별 참고

| 기술 | 게임에서 쓰는 곳 | 참고 |
|---|---|---|
| 마우스 광선과 평면 교차 | 카드를 끌어 칸에 놓기 | [cppstories: 마우스로 선택하기](https://www.cppstories.com/2012/06/select-mouse-opengl.html/) (광선 만들기, 교차, 끌기). 우리 판은 y = 0 평면 하나라 광선과 평면 교차 공식 하나면 충분 |
| 알파 블렌딩 | 반투명 미리보기, 사거리 원 | [LearnOpenGL: Blending](https://learnopengl.com/Advanced-OpenGL/Blending) (반투명은 불투명 다음에, 뒤에서 앞 순서로) |
| 조명 | 피규어 광택, 저무는 빛 | [LearnOpenGL: Basic Lighting](https://learnopengl.com/Lighting/Basic-Lighting), 수업 자료 `5. 조명모델.pdf` |
| 글자 표시 | 칩, 라운드, 타이머 숫자 | [stb](https://github.com/nothings/stb)의 `stb_easy_font.h`(텍스처 없이 빠르게) 또는 `stb_truetype.h`(폰트 파일로 예쁘게). 참고: [LearnOpenGL: Text Rendering](https://learnopengl.com/In-Practice/Text-Rendering) (FreeType 사용) |
| 텍스처 | 카드 앞면, 판 무늬 | [stb](https://github.com/nothings/stb)의 `stb_image.h`, [LearnOpenGL: Textures](https://learnopengl.com/Getting-started/Textures) |
| 디버그 UI | 밸런스 수치 실시간 조정 | [Dear ImGui](https://github.com/ocornut/imgui) (GLFW + OpenGL 3 연결 코드 포함). 게임 UI가 아니라 개발용으로만 |
| OBJ 모델 | 피규어 말 | 직접 만든 파서(Lab17에서 작성 중) |

## 3. 3D 모델 만들기

- [Blender](https://www.blender.org) (무료): 피규어 말은 **옆모습 외곽선 + 회전(Screw) 기능**으로 몸통을 만들고, 머리 장식·무기는 따로 만들어 부품별 OBJ로 내보낸다.
- 내보내기 설정: 삼각형으로 나누기(Triangulate) 켜기, 법선 포함, 크기와 중심을 원점 기준으로 맞추기.
- 모델이 준비되기 전에는 큐브·구 조합으로 대신한다(제안서에 적어 둠).
