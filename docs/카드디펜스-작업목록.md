## 회의에서 정할 것

1. 영역별로 누가 맡을지. 하고 싶은 영역과 자신 있는 영역을 서로 말해 보고 위 담당 안을 고친다.
2. 상단 정보(H9)와 결과 화면(H15)을 최명준이 맡을지. 맡지 않으면 이현수 쪽이 약 45시간으로 많아진다.
3. 각자 일주일에 쓸 수 있는 시간. 과제나 시험이 겹치는 주가 있는지.
4. 권장 기능 중 어디까지 할지. 11/16 점검 때 다시 정해도 된다.
5. 이미 정한 규칙 확인: 10라운드, 수치는 CSV 파일, 카드 팔기(칩 1개), R 키 기본 시점.
6. 제안서 최종본(`카드디펜스-제안서-v2.docx`) 확인.
